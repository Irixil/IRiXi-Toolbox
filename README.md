# IRiXi的小工具库

IRiXi的小工具库是一个常驻在 macOS 屏幕顶部的个人工具箱。它用类似灵动岛的折叠界面，把日常记录、截图、翻译、音乐和效率工具放在一起。

> 当前开发版本：`0.4.17`。本仓库目前提供源码，不提供可直接安装的签名安装包。

## 现有功能

### 灵动岛工作台

- 屏幕顶部常驻，可折叠、展开和切换功能页。
- 首页组件可调整大小、显示或隐藏。
- 快速查看并切换当前打开的窗口。
- 收起入口按系统提供的刘海安全区定位；没有刘海的屏幕按菜单栏高度提供入口。
- 主面板和相关原生窗口采用奶油纸配色，纸纹为静态背景。

### 日常效率

- 四类待办、截止时间和到期提醒。
- 首页随笔、笔记库和常用指令。
- 番茄钟、快速录音、录音资料库和实时转写。
- 可选开启的本机剪贴板历史。

### 猫头鹰番茄钟与房间布置

- 写下一件事，设置时间，开始、暂停或继续；未完成的一轮重开后先暂停，离线和休息不增加成长。
- 红围巾猫头鹰陪伴专注；支持减少动效、圆眼镜和阅读椅等收藏。
- 打开图形收藏箱，试摆灯、地毯、植物、挂画、桌子和角落装饰。位置、大小、镜像、前后次序一起保存，点“放好”才提交，取消恢复原搭配。
- 适用道具支持50%–500%等比例缩放、拖动、四方向移动和卸下；移出屏幕后可重选并“找回”。椅子和角色保持原坐姿比例。
- “全道具体验（测试）”与正常装扮、永久收藏分开保存，不增加真实专注时间或奖励。

工具箱只集成番茄钟模块；[独立猫头鹰番茄钟](https://github.com/Irixil/irixi-owl-focus)是另一个源码项目，使用自己的存档。

### 网易云音乐

- 显示当前歌曲封面、歌名、歌手和专辑。
- 歌词跟随播放进度自动高亮和滚动。
- 支持上一首、播放/暂停和下一首。
- 不提供无法可靠控制网易云的假进度条或点击歌词跳转。

### 截图、识字与翻译

- 区域、窗口和全屏截图。
- Snaploom 原生标注、复制、保存和钉图。
- Apple Vision 本机 OCR 与图片翻译。
- 中英、中日、中韩输入翻译，跨应用划词和英文朗读。
- 可选用 Codex `gpt-5.6-luna` 低思考模式进行联网解释；它使用独立的临时会话，不会读取或修改其他 Codex 任务。

### 可扩展工具

- 支持安装、启用、停用和卸载 `.irixi-tool` 本地工具包。
- 当前工具包格式仅允许本工具的独立存储，不能联网、读取其他文件或控制电脑。

## 系统要求

- Apple Silicon Mac
- macOS 13 或更高版本
- 图片翻译和输入翻译需要 macOS 15 或更高版本
- 音乐卡片需要安装网易云音乐

## 权限与隐私

- 截图、OCR 和 Apple 本机翻译默认在本机处理。
- 截图和窗口读取需要“屏幕与系统音频录制”权限。
- 跨应用划词、窗口切换和音乐控制可能需要“辅助功能”权限。
- 录音需要麦克风权限；实时转写只在用户配置通义百炼 API 后启用。
- API Key 使用 macOS 安全存储，不写入页面数据或本仓库。

## 怎样使用

打开应用后，点击屏幕顶部入口展开；也可用唤出快捷键，默认是空格，能在“设置”中修改。顶部导航切换首页、工具、待办、剪贴、笔记、录制与设置。按 Escape 或切到外部应用可以收起。

首页组件的尺寸按钮循环切换迷你、小、中、大；拖动组件调整排列，在设置中选择需要显示的组件。番茄钟右上角“更多”中填写任务和时长，用道具箱图标进入房间试摆；退出收藏箱前选择“取消”或“放好”。

随手记写完后点保存，内容会出现在笔记库；待办输入内容后回车保存，可设置截止时间。剪贴板历史需先在设置中开启。截图与输入翻译入口在工具页，首次使用按系统提示配置对应权限。录制的联网转写需先配置自己的 API；未配置时不会假装已有转写结果。

## 项目结构

```text
IRiXi-Toolbox/
├── app/       # Electron 灵动岛主程序
├── snaploom/  # 原生截图、OCR 与翻译模块
└── scripts/   # 组装脚本
```

## 本地构建

需要 Xcode 26 或更高版本以及 Node.js 22.12 或更高版本。

```bash
./scripts/prepare.sh
cd app
npm test
npm run pack
```

`prepare.sh` 会先构建 `snaploom/` 中的原生模块，再将它放入 Electron 应用的打包目录。公开分发需要发布者自己的 Apple Developer ID 和公证。
