# Security Policy

## Reporting a Vulnerability

Please use [GitHub Private Vulnerability Reporting](https://github.com/xiaoou-waou/Snaploom/security/advisories/new) for vulnerabilities, proof-of-concept material, tokens, private screenshots, or other sensitive details.

For non-sensitive security questions, open an issue at https://github.com/xiaoou-waou/Snaploom/issues.

## Scope

Reports should concern Snaploom source or builds produced from this repository. Vulnerabilities in Apple frameworks, Sparkle, Swift-WebP, or another dependency should also be reported to that upstream project.

Only the latest Snaploom source and published release, when available, are supported.
