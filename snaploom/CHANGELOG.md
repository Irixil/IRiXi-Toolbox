# Changelog

## 0.1.0 - Unreleased

Initial Snaploom source release.

### Changed

- Renamed the application, target, bundle identifier, URL scheme, and local storage namespaces to Snaploom.
- Added an original Snaploom app icon, in-app logo, menu-bar icon, and website favicon set.
- Replaced upstream maintainer and repository links with Snaploom project links.
- Removed the upstream Google OAuth client, shared imgbb key, Apple development team, and Sparkle signing key.
- Reset the public build version to 0.1.0.
- Added independent privacy, security, contribution, and provenance documentation.
- Replaced the upstream release workflow with an unsigned CI build.

The upstream project's historical changelog is preserved in UPSTREAM_CHANGELOG.md.
