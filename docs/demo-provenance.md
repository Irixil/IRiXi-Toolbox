# 首页 GIF 的制作与验证范围

这些演示于 2026-10-08 使用 `2cd9414` 的实际工具箱源码制作，对应产品版本 `0.4.17`。本次只更新文档与演示资产，没有修改应用功能。

## 画面从哪里来

工具箱页面直接加载仓库的 `app/renderer/index.html`、生产样式和脚本、`app/preload.js`。猫头鹰模块使用生产 `createOwlHost`、`FocusService`、`FileStore` 与实际内嵌 `WebContentsView`，在自己的空白演示存档中运行。

演示通过真实页面控件完成输入、点击与切页，随后捕获运行中的 UI 帧。工具箱和猫头鹰是不同渲染视图，分别捕帧后按实际窗口内坐标合成，保留原有颜色、纹理和布局。GIF 只做尺寸处理与调色板编码，没有用概念图、生成图或重新绘制的按钮替代功能画面。

录制窗口始终隐藏，不占用用户桌面。它没有加载生产 `main.js`，不会启动真实系统剪贴板监听、窗口枚举、音乐查询或权限弹窗。

## 演示数据与服务边界

- 待办、笔记和剪贴内容均为公开可展示的合成样例，使用全新独立的用户目录。
- 剪贴记录来自演示事件，展示真实页面的类型筛选与收藏，不读取、写入或粘贴用户的系统剪贴板。
- 番茄钟使用真实计时核心及独立存档，真实开始、暂停与提前换轮；不读取用户的计时、收藏或房间布局。
- 音乐、当前窗口、API 配置和原生服务使用安全演示响应。录制不调用相机、麦克风、截图或翻译服务，不请求互联网连接。
- 首页为了展示采用独立组件排列与尺寸；这是用户可配置布局的一种，不是强制默认布局。

## 展示内容

| 文件 | 操作范围 |
| --- | --- |
| `media/overview.gif` | 在首页、工具、待办、剪贴与笔记间切换 |

每个 GIF 都有同名 PNG 静态预览，README 提供独立链接，便于动图无法加载时查看。
