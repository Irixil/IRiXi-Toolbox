# 顶部折叠条适配方案

本机只读测量：Mac17,3、macOS 26.6.2；当前内建屏为 1470×956 逻辑点、2 倍缩放。系统刘海安全区高 32 点；左右顶部安全区之间的缺口为 x=646 至 x=825，宽 179 点。原先固定200点的入口比系统缺口宽21点，现已按实际系统几何统一窗口和绘制。附件实际像素尚不可见，不据自动图片描述判断外观。

最小修改如下：

1. 使用已集成原生模块只读返回 NSScreen 的显示 ID、逻辑屏幕框、安全区、左右顶部安全区，转换到 Electron 的顶部原点坐标。
2. 用显示 ID 与逻辑框匹配当前目标屏；有实际刘海缺口时直接采用其位置和宽高。缩放以逻辑点计算，不按机型名单或物理像素猜大小。
3. 无刘海屏按系统菜单栏高度提供紧凑折叠入口；原生能力缺失时走明确回退，不能把缺失读数当成测量结果。
4. 主进程窗口和渲染层条宽、动画中心共用同一度量。模式切换锚定当前屏；显示设备或度量变化后重新测量，保持原展开内容、排列和偏好。
5. 使用实际本机数据与模拟的无刘海、外接屏、负坐标、多缩放、自动隐藏菜单栏分别检验。实际本机窗口对齐和其他机器的模拟证明分开记录。

当前候选已接入只读原生屏幕几何和统一折叠条度量，并按倍率只将绘制左右与下沿向内收一个物理像素；本机2倍倍率对应0.5逻辑点。窗口命中与原展开内容不变。七项几何检查覆盖多倍率和无刘海回退；这版实际露边与点击检查仍待完成。不请求摄像头权限，不读取序列号。
