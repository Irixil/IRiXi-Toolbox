# 截图中文化与工具页头像更新

日期：2026-10-13。范围仅限内置截图/标注/翻译本地化，以及工具页「全部工具」左侧品牌头像。

## 修改

- NativeKit 从自身 framework 读取语言资源；工具箱嵌入模式使用简体中文，独立 Snaploom 原有语言选择行为保持。
- 打包复制 `.lproj`，包检查要求简体中文资源及关键文案存在，缺资源的候选不能通过。
- 字体工具条显示「系统」，字体选择器显示「系统（SF Pro）」，内部字体标识和实际字体家族名称保持不变。
- 工具页头像使用现有红围巾猫头鹰 App 图标的 256×256 PNG，不增加网络请求或依赖，不修改镜子占位图与页面布局。

## 已验证

- 独立复跑 `snaploom/scripts/test-language-manager-localization.sh <临时输出目录>`，退出 0：194 个相关 L() 字面量资源覆盖、框架真实中文读取、英文偏好下的嵌入模式、缺中文资源拒绝。
- 在 GitHub 最新 main（基线 `cb58a566819fb1cf61ee2e9971a82fe455c6b5f6`）的隔离工作区再次编译并执行上述测试，退出 0。普通发布构建不启用 `-enable-testing`。
- 本机安装在现有 0.4.19 副本上更新，不从落后源码重建宿主。头像更新仅改归档内 `renderer/index.html` 一行、增加一张 PNG，其他 238 个文件内容保持。
- 本机候选和实际安装通过深层签名、中文资源与原生模块检查，沿用同一个本机固定签名。备份后正常退出、替换唯一正式应用并重启。
- 实际正式工具页已看到猫头鹰头像，周边文案、尺寸和奶油色布局保持。用户对中文调整反馈为「基本上调整完了」。
