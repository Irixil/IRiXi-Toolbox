# 颜色与纹理分别验收

工具箱外层、导航、七个主页面和相关原生窗口保留奶油米色及黑字，去掉纸纹、颗粒和纤维叠层。逐页实际画面已查看；CSS没有外层纹理URL，原生没有纹理资源加载或绘制代码。原生翻译、账号说明、标注、颜色选择、工具条、识字结果及系统保存面板用合成文字图片核验，禁用按钮改用系统底色，避免浅底白字。

番茄钟保留原配色，只在内部增加细微纹理。原角色、房间与道具PNG及字体没有改动，画布无滤镜。纹理样式开启前后的原色、按钮和边线保持；真正桌面输入完成四尺寸拖动、大小／镜像／图层、取消、整组保存和新进程恢复。隐藏窗口截图偶有合成层未刷新的空白，不能据此冒称完整视觉通过；实际前台房间画面已另行查看。

实际桌面通过快速导航、同页连续点击、输入中切页、四尺寸切页；后续独立检查通过外部自有窗口点击收起、Escape收起和刘海入口点击展开。首次完整导航脚本在末尾未找到外部测试窗而失败，保留该失败和后续具体补测，没有重写为整条通过。本机实际折叠绘制左右及底边各内收一个物理像素。

最终按钮修正只改变原生按钮底色，打包主页面、导航及房间ASAR与已测候选完全一致；原生窗口为修正后的真实源码重新构建、逐图核验。旧57黑色候选和旧56外层纸纹画面均为历史。
