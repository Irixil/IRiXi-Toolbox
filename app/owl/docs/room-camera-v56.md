# 同一房间的竖版适配

最大竖版先显示同一张1024×1536世界中的完整构图。较小尺寸等比例缩小，背景和物件由同一个相机绘制；没有另一张独立 `cover` 背景，也不再按不断改变高度的中间网格行决定物件大小。

收藏侧栏打开时，房间等比例适配旁边可见区域。布置工具条不会再改变相机比例；小尺寸保留侧栏和可见房间，避免原底部收藏面板把房间全部盖住。画布仍覆盖整个模块，UI遮挡之外可以自由拖动；可把道具移出屏幕，再通过原“找回”入口恢复位置。

原角色、背景、道具PNG、世界坐标、大小、镜像、图层、计时和存档格式保持原样。修改只影响显示。高分屏画布的两个像素轴分别取整，回到逻辑尺寸后仍为同一等比映射；角色点击与道具拖动共用同一个逆向换算。

当前已检查：四种尺寸的真实素材隐藏窗口绘制、装扮侧栏、主要布置控件、可信渲染器输入拖动、取消、整组保存和新进程恢复；独立入口计时与双视图、恢复另有隔离检查。逻辑回归通过。测试写入独立本地资料，没有修改正常装扮或增加成长。

这些是隐藏窗口和受控资料证据，不能代替原工具箱内嵌模块的桌面实机操作。新竖版参考图的实际像素尚未取得，当前不能声称已对照或已获得用户审美认可。实际四尺寸、连续拖动、保存重开等检查完成后，才更新正式安装。
