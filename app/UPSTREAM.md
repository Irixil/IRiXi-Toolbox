## 本仓库的改动方向

本仓库取消黑猫桌宠界面，在上游工作台中加入受控 Agent 交接能力，包括：

- 主动或定时发起交接；
- 简单提问与完整确认；
- 连接 `packages/agent-service-v2`；
- 后台续做、等待用户和结果验收；
- 接受、继续、撤回和结束；
- Codex Remote 计划入口。

TO-DO Panel 原有的待办、笔记、链接、录音、密钥、设置、首页组件和本机完成提醒继续保留，除非后续产品决定另有记录。

## 更新上游时

1. 记录新的上游仓库地址和完整提交哈希。
2. 先比较 `LICENSE`、依赖、第三方声明、素材和构建脚本。
3. 单独检查上游数据结构、窗口尺寸、权限和系统服务变化。
4. 合并时保留本仓库的 Agent 安全边界，不直接接受上游任务内容中的指令。
5. 回归上游核心页面和完整 Agent 交接流程。
6. 更新本文件中的固定提交，说明主要差异。

不要只写“同步最新版”。每次导入都必须能追溯到一个完整提交。
